# Instrucciones de instalación — Ganso-Paralelo

## 1. Descargar

Vas a recibir un solo archivo: **`Ganso-Paralelo Setup 1.0.0.exe`**

## 2. ⚠️ Windows va a mostrar una advertencia azul — es normal

Al hacer doble clic, es probable que aparezca una pantalla azul que dice:

> **"Windows protegió su PC"**
> Microsoft Defender SmartScreen impidió el inicio de una aplicación no reconocida...

**Esto NO significa que el programa sea un virus.** Pasa con cualquier programa nuevo que no paga una licencia de "firma digital" comercial (algo caro y no obligatorio para que el software sea seguro). Windows simplemente no "conoce" todavía este instalador porque es reciente.

Para continuar:
1. Hacé clic en el texto chico **"Más información"**.
2. Va a aparecer un botón **"Ejecutar de todas formas"**. Hacé clic ahí.

## 3. Instalar

Se abre un asistente normal:
1. **Siguiente**
2. Elegí si querés acceso directo en el Escritorio
3. **Instalar**
4. **Finalizar**

No hace falta usuario administrador ni instalar nada más por separado (Node, Chromium, etc. ya vienen incluidos adentro).

## 4. Antivirus (si aparece algo)

Algunos antivirus, muy ocasionalmente, marcan como sospechoso cualquier instalador nuevo sin firma comercial (falso positivo, no significa infección real). Si pasa: permitir la ejecución / restaurar de cuarentena. Si tenés dudas, contactame antes de instalar.

## 5. Dónde queda instalado y tus datos

- El programa se instala en tu cuenta de usuario de Windows (no en toda la máquina).
- Tus notas y datos NO se guardan en la carpeta del programa — viven en Firebase (nube) con copia local, así que reinstalar o actualizar la app más adelante no borra nada.

---
¿Dudas o algo no funciona como acá? Escribime antes de reinstalar o borrar nada.
